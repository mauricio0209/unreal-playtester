Red door stayed closed with red key

Design document

Every door starts closed and locked. To open a door the player stands next to it and interacts with it. A door opens only if the player is carrying the key of the same color; otherwise it stays shut. A key opens only the door of its own color. The blue door is the heavy door to the treasure room.

Check written by the model

red_opens_with_key: Interacting with the red door up close while carrying the red key must open it.

Check JSON
{
 "after": [
  {
   "and": [
    {
     "did": "interact"
    },
    {
     "==": [
      {
       "var": "ActorStates.RedKey"
      },
      null
     ]
    },
    {
     "<": [
      {
       "dist": [
        "PlayerLocation",
        "ActorLocations.RedDoor"
       ]
      },
      150
     ]
    }
   ]
  },
  {
   "==": [
    {
     "var": "ActorStates.RedDoor"

    "closed"
   ]
  }
 ]
}

Picked up RedKey then walked to RedDoor within 44cm and interacted, but state shows RedDoor still closed and image shows blank wall/door not opened
